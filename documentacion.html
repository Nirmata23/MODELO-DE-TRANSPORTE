Sobre el proyecto

Este sitio documenta el procedimiento para resolver el problema de transporte planteado por el catedrático. El modelo se resolvió a mano con tres métodos de solución inicial y después se programó para comprobar los resultados.

Los valores que aparecen en todas las páginas no están escritos a mano en el sitio: se calculan en el momento a partir del archivo datos.json, con el mismo algoritmo en JavaScript y en Python. Los tres métodos reproducen exactamente los totales obtenidos en las hojas de trabajo.

Programa en Python

El mismo modelo resuelto desde la consola, útil para comprobar los resultados sin abrir el navegador:

python3 python/transporte.py            # resuelve con los tres métodos
python3 python/transporte.py --metodo vogel
python3 python/transporte.py --json     # salida en JSON
python3 python/pruebas.py               # comprueba contra las hojas
