Calculadora interactiva

Cambia los costos, las ofertas o las demandas y el sistema vuelve a resolver el modelo con los tres métodos.

Datos del modelo

Puedes editar cualquier casilla: nombres, costos, ofertas y demandas. También puedes agregar o quitar filas y columnas.

Cargando…

Si el problema no queda balanceado, el sistema agrega automáticamente un origen o un destino ficticio con costo 0 antes de resolver.
